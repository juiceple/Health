# FitLog

운동 기록 · 체중 관리 · AI 자세 코칭을 한 번에 하는 모바일 웹앱(PWA).

## 기능
- **운동 기록**: 종목/세트(무게·횟수) 기록, 지난번 기록 자동 표시, 휴식 타이머, 볼륨 계산, 히스토리
- **체중 관리**: 일별 체중·체지방 기록, 추이 그래프(목표선), 7/30일 변화, BMI
- **운동법 라이브러리**: 41개 종목의 단계별 자세, 흔한 실수, 팁, 타겟 근육, 개인 최고 기록
  - **3D 동작 시범**: three.js로 근육 형태의 3D 인체를 렌더링해 전 종목 시연 — 주동근(청록)·보조근 하이라이트, 3D 기구(바벨·덤벨·벤치·케이블), 단계별 캡션, 실시간 관절 각도, 잘못된 자세 예시(빨간색), 슬로모션. WebGL이 없으면 2D로 대체
  - **유튜브 영상**: 전 종목 추천 자세 영상(한국어) 기본 탑재, 원하는 영상으로 교체·검색 가능
- **AI 자세 코치**: 카메라 + MediaPipe Pose로 관절 각도를 실시간 분석
  - 지원: 스쿼트·고블릿 스쿼트, 런지·불가리안 스플릿 스쿼트, 푸쉬업, 덤벨·해머·바벨 컬, 덤벨 숄더 프레스
  - 반복 횟수 자동 카운트, 가동범위 부족·상체 숙임·엉덩이 처짐 등 교정 피드백, 한국어 음성 안내
  - 결과를 오늘 운동에 세트로 저장
  - 영상은 기기 안에서만 처리되며 전송·저장되지 않음

데이터는 브라우저 localStorage에 저장되며, 홈 화면에서 JSON 백업/복원할 수 있습니다.

## 개발
```bash
npm install
npm run dev      # http://localhost:5173 (같은 Wi-Fi의 폰에서는 Network 주소로 접속)
npm test         # 자세 분석 로직 테스트
npm run build
```

> 폰에서 카메라를 쓰려면 HTTPS가 필요합니다. Vercel 등에 배포하거나 `vite --https` 같은 방법으로 접속하세요.

## 구조
- `src/pose/analyzers.ts` — 운동별 각도 계산·반복 카운트·자세 판정 (순수 함수, 테스트 포함)
- `src/pages/Coach.tsx` — 카메라, MediaPipe 실행, 스켈레톤 오버레이, 음성 피드백
- `src/motion/` — 2D 인체 리그(FK/IK), 종목별 키프레임 모션, 3D 근육 인체 렌더러(`body3d.ts`)
- `src/data/exercises.ts` — 운동 라이브러리
- `src/store.ts` — localStorage 기반 데이터 저장
